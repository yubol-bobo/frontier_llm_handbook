All sources are shallow clones retaining the current working tree; they do not include full history, uninitialized submodule contents, or large Git LFS file contents. Model weights and datasets are not in this directory.

## Usage notes

- Local sources are independent; the learning repository uses `.gitignore` to exclude `sources/` and avoid accidentally committing nested repositories.
- Study notes cite pinned SHAs. When manually updating sources later, create new study records and record new snapshots without overwriting the basis of past experiments.
- `python tools/clone_repos.py` only clones missing repositories and checks existing origins; it does not pull/reset existing sources.
- `python tools/snapshot_sources.py` records the current versions again; run it only when the source manifest needs updating.
- Only gitlinks are recorded for submodules; fetch the corresponding dependencies according to a project's instructions when it needs to be compiled.
