# 一次训练研究决策

## 问题与可否证假设

- 目标能力或系统指标：
- 假设及预测方向：
- 哪个结果会反驳假设：
- 源码 / 论文依据及其公开范围：

## 对照与预算

- 基线、候选、唯一变化或不可分离的变化组：
- 模型 / tokenizer / 数据 / harness / verifier 版本：
- token、样本、计算、时长与评估口径：
- 随机性、重复次数与统计不确定性：
- 环境和资源条件：
- 实际命令（待执行须注明）：

## 结果与决策

- 实际结果文件、日志、trace 与 hash：
- 所有失败 / 取消 / 丢弃样本如何计数：
- 观察与解释分开写：
- 保留、拒绝还是继续取证：
- 适用边界、回退点与下一步：
