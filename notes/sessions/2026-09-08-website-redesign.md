# 2026-09-08｜网站视觉与交互升级

用户希望已有网站拥有现代、高品质的视觉与更生动的学习交互。本次工作改进学习界面，课程、固定源码证据及已执行实验的范围没有变化。

## 已实现

- 石墨深色学习空间，辅以紫色、薄荷绿与蓝色阶段标识；独立的浅色阅读主题。本站提供 Geist 和 Noto Sans SC 可变字体，使用 Lucide 图标并保留许可证。
- 首页改为继续学习面板、实验入口、阶段选择与课程卡片。下一模块与验收计数来自真实个人记录，课程顺序仍来自 ROADMAP。
- 知识地图按实际模块位置绘制关联线，保留主题关联与有方向先修的区别；键盘选择保持焦点，窄屏使用模块列表及关系详情。
- 实验保留稳定的概率节点，用动画展示概率改变、上一次更新前位置、实际计算的 loss 轨迹；有效目标与分组归一化差异可视化。更改单 token 参数重置操作历史，恢复实验参数不清空当前页自测作答。
- 长文目录跟踪、阅读位置线、随主题更新的文档关系图，以及尊重减少动态效果偏好的过渡。
- 沿用已有学习记录格式与存储键，主题偏好单独存储；笔记和验收证据仍仅保存在当前浏览器。

## 验证范围

构建与 Node 检查覆盖原有课程、源码链接和数学验证，并增加卡片完整性、继续学习、关系语义、真实 loss 曲线、分组展示与本站字体文件检查。只读代码审查发现并修正了地图边缘连线裁切、同页导航 observer 恢复、离开实验再返回后的滑杆状态，以及暗色图表和未关联节点的可读性问题。

本次未执行浏览器截图或浏览器视觉测试；自动检查和静态审查不代表完整浏览器兼容性验证。发布沿用 main 的 GitHub Actions / Pages 流程，实际部署记录见仓库 Actions。

本地结果：`npm run check` 的 17 项检查通过；资料库校验检查了 19 个仓库、511 条本地链接和 216 条固定源码链接，无错误。本地首页、CSS、脚本及三份字体/图标许可证均返回 HTTP 200。

没有新增模型训练执行，也不把视觉升级计为任何课程或上游源码的学习完成。技术维护方式见 [网站说明](../../website/README.md)。
