# 2026-09-08｜中英双语网站与术语校核

用户希望网站提供中文和英文两种选项，并确保英文技术术语准确。本次给界面、核心课程、专题、手册、源码笔记、连接专题与模板加入完整英文版本，共 51 篇站内资料。

## 实现与证据

- 顶部语言选择、独立的本地语言偏好、可分享的 `?lang=zh` / `?lang=en` 入口；课程和实验继续共用原有学习记录。
- 翻译仅处理编写好的界面文案和教材；个人笔记、搜索词、源码标识与数值不进行翻译。切换时保留当前模块、表单、自测与数学实验状态。
- 英文 Markdown 保留模块 ID、原有章节链接别名和固定源码引用；译文清单记录中文源文件 SHA-256，原稿变化后构建要求重新核对译文。
- 新增 33 项中英术语对照。核对依据包括 NVIDIA 并行文档、PyTorch FSDP 文档、PaLM、DPO 与 DeepSeekMath 原论文，链接保存在 [术语表](../../GLOSSARY.md)。
- 将原文 MFU 的笼统表述修正为 model FLOPs utilization；明确 `padded_vocab_size` 补齐的是词表维度。元数据也收紧 master weights 的适用条件与奖励实验已验证范围。

## 检查范围

翻译稿检查章节层级、列表、表格、链接、固定 SHA、代码及数值示例。代码审阅修正了首次加载时切换语言的竞态、阅读位置被原锚点覆盖，以及关系图文字展开状态的恢复顺序。

自动检查覆盖两种语言的内容对应、旧锚点、完整链接、界面文案、个人数据边界及既有数学反例。未进行浏览器截图或浏览器视觉测试，也未新增模型、GPU 或训练集群执行。译文不是外部认证，原有课程完成状态与实验执行范围保持原记录。
