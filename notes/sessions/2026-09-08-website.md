# 2026-09-08｜交互学习网站

用户希望将已有资料库制作成网站，在 GitHub Pages 发布，让读者更高效、互动地学习前沿 LLM 端到端训练与工程知识。

## 本次实现

- [网站](https://yubol-bobo.github.io/frontier_llm_handbook/) 从已有资料生成：51 篇 Markdown、16 个核心模块、6 个专题、19 个固定源码项目。
- 三阶段课程导航、中文/英文全文搜索、站内阅读、目录和源码入口；7 条有文档依据的知识连接，以及从 ROADMAP 提取的 19 条实线先修。
- 将实验 002 的局部数学做成浏览器教学单元：logits/标签/学习率、稳定 softmax 与交叉熵、解析梯度、一次参数更新、mask 和分组比较，附四道自测。
- 模块笔记、工程证据、自主验收状态；个人数据仅存在当前浏览器，可导出/导入。页面访问和自测不自动判定结业。
- GitHub Actions 构建并发布 `main`，PR 只检查；不为网站额外克隆上游、下载模型或运行 GPU。

## 验证与边界

自动检查包含固定课程身份、所有生成的站内文档与锚点、源码链接映射、Markdown 安全渲染、独立梯度有限差分、既有 Python 实验数值、63 种非空 mask 的三种分组不变性、空批次、非法输入、进度备份格式和搜索。代码审阅修正了数值预览边界、多标签页记录同步、未知文档路由与专题编号显示。

本次未执行浏览器截图或视觉测试；本地预览入口经 HTTP 检查可访问。数学与内容自动检查不等于完整浏览器兼容性验证，也不代表模型训练已执行。上线状态和发布日志以仓库 GitHub Actions / Pages 为准。

教材依然在原始 Markdown 中维护，网站不另写一套课程顺序。后续仍优先补完整 decoder 教学与实验，再把已有课程逐步转成可交互、可验收的学习单元。开发与发布流程见 [网站说明](../../website/README.md)。
